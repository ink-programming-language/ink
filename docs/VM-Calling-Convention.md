# VM 调用约定

本文定义 Ink VM 函数的调用布局；执行器尚未实现。宿主 C ABI 由 native adapter 单独处理。

## 基本规则

| 项目 | 约定 |
| --- | --- |
| 地址 | 64 位 VM 地址；大小、偏移均以字节计。 |
| 栈方向 | 向高地址增长。 |
| `sp` | 指向首个空闲字节，有效栈区间为 `[StackBegin, sp)`。 |
| `bp` | 指向当前函数的调用保存区，函数体内保持不变。 |
| 对齐 | 调用区起点、参数槽、返回槽和调用边界均按 8 字节对齐。 |
| 参数 | 全部通过栈传递，按声明顺序从低地址向高地址排列。 |
| 返回值 | 通过调用方预留的栈槽传递；`void` 不占返回槽。 |
| 调用头 | 仅可变参数函数调用包含 24 字节预留区；非可变参数调用没有该区域。 |
| 回收 | 被调用方回收局部空间和保存区；调用方回收调用区。 |
| EFLAGS | 调用后不可依赖原值；不隐式保存、恢复。 |

## 普通调用栈布局

以下为非可变参数函数的调用布局：

```text
低地址
┌──────────────────────────────┐
│ 调用方已有的帧空间           │
├──────────────────────────────┤ ← CallBegin
│ 返回槽                       │
│ 参数 0                       │
│ 参数 1                       │
│ ……                           │
├──────────────────────────────┤ ← bp
│ 旧 bp                        │  8 字节
│ 返回 pc                      │  8 字节
├──────────────────────────────┤ ← bp + 16
│ 被调用方局部变量、临时空间   │
├──────────────────────────────┤ ← sp
│ 尚未使用的栈容量             │
└──────────────────────────────┘
高地址
```

普通调用的调用区为 `[CallBegin, bp)`，只包含返回槽和参数区。保存区为 `[bp, bp + 16)`。

### 可变参数调用预留区

仅调用可变参数函数时，在参数区末尾与 `bp` 保存区之间额外预留 24 字节。是否存在该区域由函数签名决定。

| 相对 `bp` 的偏移 | 预留字段 | 大小 |
| --- | --- | --- |
| `-24` | `PayloadBytes: u64` | 8 字节 |
| `-16` | `TypeTableAddress: u64` | 8 字节 |
| `-8` | `TypeCount: u64` | 8 字节 |

这里只预留区域和字段位置；字段取值、类型表格式及读取规则另行约定。

## 参数和返回槽

`ValueBytes(T)` 表示类型在 Ink VM ABI 中的值表示大小。当前直接传递规则适用于对齐要求不超过 8 字节的值；更高对齐类型的传递方式另行约定。

非可变参数调用的布局公式：

```text
SlotBytes(T) = max(8, alignUp(ValueBytes(T), 8))
ReturnBytes  = 返回 void 时为 0，否则为 SlotBytes(ReturnType)
CallBytes    = ReturnBytes + Σ SlotBytes(ParameterType)

CallBegin           = bp - CallBytes
ReturnSlotAddress   = CallBegin
ParameterAddress(i) = CallBegin + ReturnBytes + Σ SlotBytes(ParameterType(j)), j < i
```

调用区大小及槽位偏移在编译时由签名确定，参数和返回槽可直接通过 `bp + 常量` 访问。普通调用不生成或读取调用头。

| 值表示 | 有效数据大小 | 槽大小 |
| --- | --- | --- |
| `i8` | 1 | 8 |
| `i32`、`f32` | 4 | 8 |
| `i64`、`f64` | 8 | 8 |
| `ptr<T>`：VM 地址，与 `T` 大小无关 | 8 | 8 |
| 12 字节聚合值，对齐不超过 8 | 12 | 16 |
| 24 字节聚合值，对齐不超过 8 | 24 | 24 |
| 空值类型 | 0 | 8 |

槽位扩充不改变值的类型或位宽；填充字节不承载有效数据。引用语义类型传递引用值，实例大小不作为引用槽大小。值的构造、复制和销毁遵循语言语义。

### 大于 8 字节的值

对齐要求不超过 8 字节的值直接连续存放，占用多个 8 字节槽。被调用方按签名访问整块值；返回值使用同样的布局规则。

结构体内部的字段偏移、对齐和已有填充保持类型布局不变，不逐字段扩充为 8 字节槽；只在整个值的末尾补齐到 8 字节倍数。新增的尾部 padding 不承载有效数据，不要求清零。

例如参数依次为 12 字节结构体 `S` 和指针 `ptr<T>`：

```text
参数区相对偏移
[ 0, 12)  S 的值
[12, 16)  S 参数槽的尾部 padding，不要求清零
[16, 24)  ptr<T> 的 64 位 VM 地址
```

调用方按类型的复制或移动规则准备 `S` 参数。允许按字节复制的值仅复制其值表示大小：12 字节源值不会因为目标槽为 16 字节而扩大读取范围。

### 指针

`ptr<T>` 的值是 64 位 VM 地址，参数槽和返回槽均占 8 字节。调用传递地址值，被指对象仍位于原存储中。

| 操作 | 效果 |
| --- | --- |
| 修改形参指针的地址值 | 只修改本次调用的指针副本。 |
| 通过指针写入被指对象 | 在类型及访问权限允许时，修改原对象。 |

指针槽按 8 字节对齐；被指对象须满足 `T` 自身的对齐和生命周期要求。普通 VM 地址不能直接作为宿主指针使用，native 边界由 adapter 转换。

## 普通调用和返回

| 阶段 | 操作 |
| --- | --- |
| 调用方准备 | 记录 `CallBegin = sp`，预留 `CallBytes`，写入参数。 |
| `call` | 令 `FrameBP = sp`；写入 `[FrameBP] = bp`、`[FrameBP + 8] = NextPC`；设置 `bp = FrameBP`、`sp = FrameBP + 16`、`pc = EntryPC`。 |
| 函数体 | 从 `bp + 16` 开始预留局部空间；访问参数和返回槽；嵌套调用独立准备调用区。 |
| 返回前 | 完成返回值写入及本层清理。 |
| `ret` | 读取 `SavedBP = [bp]`、`ReturnPC = [bp + 8]`；设置 `sp = bp`，再恢复 `bp = SavedBP`、`pc = ReturnPC`。 |
| 调用方收尾 | 读取或转存返回值，将 `sp` 恢复为 `CallBegin`。 |

调用方负责调用边界的 8 字节对齐；局部空间不足整 8 字节时，显式计入填充。`sp` 调整不自动取整，普通调整不得回收至当前 `bp + 16` 以下；保存区由 `ret` 回收。

地址计算、栈范围及控制转移目标必须先检查，通过后再提交调用或返回的状态变化；失败通过 trap 报告。栈上地址仅在对应存储存活期间有效，返回值不得指向已回收的本层局部存储。

## 示例：`sum(i64, i64) -> i64`

调用方初始 `sp = 1024`：

```text
ReturnBytes  = 8
CallBytes    = 8 + 8 + 8 = 24
```

| 地址区间 | 内容 | 被调用方中的位置 |
| --- | --- | --- |
| `[1024, 1032)` | 返回值 | `bp - 24` |
| `[1032, 1040)` | 参数 0 | `bp - 16` |
| `[1040, 1048)` | 参数 1 | `bp - 8` |
| `[1048, 1056)` | 旧 `bp` | `bp` |
| `[1056, 1064)` | 返回 `pc` | `bp + 8` |

```text
调用方预留 24 字节   sp = 1048
call 进入 sum       bp = 1048，sp = 1064
sum 写入返回槽      [bp - 24] = [bp - 16] + [bp - 8]
ret                 恢复调用方 bp、pc，sp = 1048
调用方取得返回值    读取 [1024, 1032)
调用方回收 24 字节   sp = 1024
```
