# 泛型函数

泛型函数使用显式的 `::[...]` 实例化语法。泛型声明保留 AST；每组具体实参生成一份普通函数 IR，解释器、字节码、编译期执行和 LLVM AOT 共用该 IR。

```ink
func identity[T: type](Value: T): T
{
  return Value;
}

func first[T: type, N: u64](Values: [T; N]): T
{
  return Values[0];
}

func add[T: type = i32, N: T = 2](Value: T): T
{
  return Value + N;
}

func main(): i32
{
  var A = identity::[i32](20);
  return A + add::[N = 2, T = i32](20);
}
```

## 参数和实参

- `T: type` 接收具体类型，包括标量、指针、定长数组和已定义的非泛型 class。
- 值形参接收 bool 或定宽整数常量。整数的位宽、符号和完整位模式均参与实例身份；整数常量按泛型形参类型检查范围，不执行整数截断。
- 泛型形参可以引用前面的类型形参，如 `N: T`。缺省实参在定义环境及前面已绑定的泛型形参中求值；`::[]` 显式使用所有缺省值。
- 支持位置实参和 `Name = Value` 命名实参。位置实参须在命名实参之前；重复、未知、缺失和过多实参均报告源码错误。
- 显式实参在使用点按书写顺序求值一次。多个候选共享求值结果，命名映射不改变副作用顺序。
- `identity::[i32]` 也是具体函数值，可以赋给局部变量并调用。

当前要求显式泛型实参，不从普通实参推导类型。普通函数与泛型函数可以同名；普通调用选取普通候选，`::[...]` 选取泛型候选。泛型参数包、泛型 class、泛型实例方法、类型值返回、泛型原生导入/导出，以及浮点、字符串、指针和聚合值形参尚不支持。运行时形参沿用普通函数的固定位置参数规则。

## 定义环境、实例和重载

定义环境保存定义处可见的名字与重载集合，并冻结已初始化的可持久化编译期值。调用点的同名局部变量不会覆盖定义环境。局部泛型可以使用外层泛型绑定；不能捕获另一个函数的运行时参数或局部变量。

实例缓存归 `SemanticContext` 所有，以泛型声明身份和规范实参序列为键。普通调用参数不进入缓存键。函数签名先发布，选中候选后才分析其函数体；同一实例的普通递归、互递归和重复调用复用同一个具体函数。未使用泛型体和未选中重载的函数体不检查。仅返回类型不同或泛型参数改名不能构成新的重载。

泛型重载仍使用普通函数的精确类型匹配和整数字面量排序规则；没有模板偏序或 SFINAE。替换时的非法签名是源码错误。存在多个泛型声明候选时，签名类型计算和省略的缺省实参不得包含调用、递增递减或嵌套泛型应用，避免试探候选产生副作用；可以在使用点先求值并显式传入。

`comptime func` 的具体实例只能在编译期使用。普通泛型实例可用于运行时及编译期执行。编译期调用不能执行正在生成的函数体，违反时报告 `INK-S0038`。静态分支仅检查被选中的分支。

## 模块、保存和资源限制

`from library import identity as id;` 与 `import library as lib; lib.identity::[i32](42)` 保持定义模块的可见性与词法查找规则。实例符号包含定义身份、泛型实参和具体签名。字节码对象保存被使用的实例及其必要私有依赖；不同对象可以各自包含私有实例副本。链接后的镜像不依赖源码，输入对象顺序不影响调用结果。

IR 文本和二进制归档保存实例身份及泛型实参类型，含未出现在运行时签名中的类型。归档恢复具体 IR，不恢复前端实例缓存或重新实例化模板。

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| `INK_SEMANTIC_GENERIC_DEPTH_LIMIT` | `64` | 嵌套泛型分析深度，内部硬上限 `128` |
| `INK_SEMANTIC_GENERIC_INSTANCE_LIMIT` | `4096` | 一个语义上下文内累计创建的候选实例数 |

泛型声明或应用错误使用 `INK-S0061`、`INK-S0062`；超出预算使用 `INK-S0063`；签名或定义环境的循环依赖使用 `INK-S0064`。已失败的实例不能发布为可执行产物。

## 测试

`src/testcase/semantic/generic_function_test.cpp` 覆盖实例复用、类型和值参数、缺省与命名实参、调用顺序、递归、重载、局部定义、作用域、编译期执行、诊断、预算及 IR 归档往返。

`src/testcase/execution/programs/generic_*.ink` 逐项输出用例名和 `PASS`，核对退出码、完整 stdout 和空 stderr，并进行保存字节码的独立执行。`execution/multifile/generic_functions` 覆盖模块别名、私有依赖和对象链接顺序。`AOTClassTest.Generic*` 对相同程序执行 LLVM O0/O2 差分检查。

```powershell
cmake --build build --config Release
ctest --test-dir build -C Release -R 'Generic|generic_functions' --output-on-failure
```
