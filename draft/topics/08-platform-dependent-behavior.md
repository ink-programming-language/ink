# 议题 08：平台相关行为（PDB）

> 状态：已确认，议题 61 补充编译期执行
> 确认日期：2026-08-01

## 1. 定义

平台相关行为（platform-dependent behavior，PDB）是由 Ink 明确允许、但具体效果取决于目标平台的行为。

PDB 用于表达以下情况：

- 不同目标平台的原生行为不同；
- 为所有平台强制统一结果需要额外运行时指令、检查或分支；
- Ink 选择保留目标平台的原生行为，不为统一结果支付隐含成本。

PDB 是 Ink 程序语义的一部分，不是未定义行为（UB），也不是由编译器任意选择结果的未指定行为。

## 2. 目标平台配置

每个 Ink 目标平台配置必须记录其所有 PDB。平台配置至少由以下部分共同确定：

- 目标 ISA；
- ABI；
- 操作系统约定；
- 会影响该行为的目标特性；
- 对没有原生机器操作的类型所采用的编译器或运行库降低规则。

每项 PDB 必须说明它会：

- 产生什么值；
- 产生哪一种目标平台 trap；
- 或产生其他明确记录的目标平台效果。

同一目标平台配置中的 PDB 不得因为优化级别变化而任意改变。交叉编译必须使用目标平台的 PDB，不能使用编译器宿主平台的行为。

## 3. 编译器约束

当某项运算可能进入 PDB 输入域时，编译器必须保留该目标操作，且不得：

- 假设触发 PDB 的路径不可达；
- 将 PDB 当作 UB、poison 或 `unreachable`；
- 根据“程序不会触发 PDB”反推操作数范围；
- 利用上述假设删除或合并控制流；
- 推测执行原本不一定执行的 PDB 运算；
- 删除结果未使用但可能产生目标平台 trap 的 PDB 运算；
- 使用宿主平台行为对 PDB 进行常量折叠。

如果编译器已经独立证明输入不在 PDB 输入域内，则该次运算是普通的固定语义运算，可以按照普通规则优化。

将 PDB 运算选择成当前目标平台的机器指令属于代码生成，不属于利用 PDB 推导程序性质。

## 4. 不插入隐式运行时成本

编译器不为了把一种平台的 PDB 修正成另一种平台的结果而自动插入：

- 输入范围检查；
- 条件分支；
- 结果修正；
- 人工 trap；
- 仅用于统一跨平台结果的运行库调用。

当目标平台没有对应的原生操作时，编译器或运行库仍需完成该类型本身所要求的常规降低。该降低规则属于目标平台配置的一部分，但不得额外模拟另一个平台的 PDB。

## 5. 程序依赖 PDB

平台专用代码允许有意依赖目标平台已经记录的 PDB：

```ink
// 仅示意；目标条件编译语法由后续议题确定。
comptime if (target.arch == .x86_64) {
    // 可以依赖 x86_64 目标配置记录的 PDB。
}
```

需要跨平台一致结果的程序应避免进入 PDB 输入域，或者主动使用标准库提供的 `checked_*`、`wrapping_*` 等固定语义 API。由这些显式 API 产生的额外成本是程序主动选择的成本。

## 6. 诊断

当编译器静态发现程序必然或很可能触发 PDB 时，可以产生 warning。

该 warning：

- 不改变目标平台行为；
- 不把操作变成 UB；
- 不授权优化器假设该路径不可达；
- 可以由平台专用代码通过统一诊断控制机制显式关闭。

## 7. 编译期执行

编译器不得使用宿主机器直接执行 PDB 运算来决定交叉编译结果。

议题 61 的编译期执行器始终接收明确的 `TargetContext`，并按照编译目标的平台配置解释 PDB。目标规则产生值时，编译期执行得到同一值；目标规则产生 trap 时，强制 `comptime` 求值无法完成并产生编译错误。该错误只表示编译期表达式不能形成结果，不授权优化器把普通运行时代码中的相同 PDB 路径当作 UB 或不可达。

目标配置必须提供可由解释器模拟的 PDB 语义。交叉编译时即使宿主机器能够直接执行形式相似的指令，也不能用宿主结果替代目标结果。

## 8. LLVM 实现要求

当 LLVM IR 对同一输入规定 UB 或 poison 时，Ink 编译器不能直接使用该 LLVM 指令表示 PDB。PDB 必须以专用运算保留到目标相关的降低阶段。

Ink 的 LLVM 后端使用 LLVM 提供的 inline-asm API 生成带 `sideeffect` 的目标指令，不要求修改 LLVM 源码，也不要求注册新的 LLVM intrinsic。

非规范性实现方案见 [`../implementation/llvm-pdb-lowering.md`](../implementation/llvm-pdb-lowering.md)。
