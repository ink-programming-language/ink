# 议题 09：整数除法与移位

> 状态：已确认
> 确认日期：2026-08-01

本议题使用 [`08-platform-dependent-behavior.md`](./08-platform-dependent-behavior.md) 定义的 PDB。

## 1. 普通除法与余数

在除数非零，并且有符号除法不是 `MIN / -1` 时，整数 `/` 和 `%` 具有统一语义：

- 有符号除法向零截断；
- 有符号余数与被除数同号，或者为零；
- 满足 `a == (a / b) * b + (a % b)`；
- 无符号除法和余数使用通常的非负整数语义。

```ink
let q: i32 = -7 / 3; // -2
let r: i32 = -7 % 3; // -1
```

这些正常输入的结果不是 PDB。

## 2. 除法边界 PDB

以下操作是 PDB：

- 任意整数类型除以零；
- 任意整数类型对零取余；
- N 位有符号整数的 `MIN / -1`；
- N 位有符号整数的 `MIN % -1`。

目标平台配置必须分别说明这些操作是产生目标平台结果还是发生目标平台 trap。编译器不为它们生成跨平台修正代码。

对于目标平台没有原生除法的整数宽度，例如许多 64 位平台上的 `i128` 和 `u128`，编译器或运行库采用的降低规则必须作为该目标平台的 PDB 一并记录。

## 3. 移位

移位操作的右操作数使用 `ptrsize`，因此不存在负移位量。

对于 N 位左操作数，当移位量小于 N 时，行为统一如下：

- 左移丢弃移出高位的比特，并在低位补零；
- 无符号右移在高位补零；
- 有符号右移是算术右移，在高位复制符号位。

```ink
let a: u8 = 0b1000_0001u8 >> 1; // 0b0100_0000
let b: i8 = -4i8 >> 1;          // -2
```

当移位量大于等于左操作数的类型位宽时，结果是 PDB。编译器不自动对移位量取模，不插入范围检查，也不自动 trap。

目标平台配置必须说明超位宽左移、逻辑右移和算术右移的具体行为，包括窄整数经过机器寄存器宽度提升后产生的行为。

## 4. 显式固定语义操作

标准库可以提供跨平台固定语义的显式操作：

```ink
value.wrapping_shl(count) // 显式按类型位宽规范化 count
value.wrapping_shr(count)
value.checked_shl(count)  // 移位量越界时返回可选结果
value.checked_shr(count)
value.checked_div(other)
value.checked_rem(other)
```

这些操作可以产生必要的额外指令，其成本由程序主动选择。

## 5. 旋转操作

旋转不通过超位宽普通移位间接表达。标准库或后续内建操作可以提供 `rotate_left` 和 `rotate_right`，并将旋转量按类型位宽规范化；具体 API 在标准库议题中确定。
