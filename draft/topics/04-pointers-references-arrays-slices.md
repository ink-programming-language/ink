# 议题 04：指针、引用、数组与切片

> 状态：已确认，议题 31—33、43、44、54 补充
> 确认日期：2026-08-01

## 1. 原始指针

`T*` 表示可保存、可复制的原始地址。

- `T*` 可以为空，使用 `null` 表示空指针；
- 不使用“`T*` 非空、`T*?` 可空”的双层设计；
- 需要静态非空语义时使用标准库 `NonNull<T>` 包装；
- 指针不拥有目标对象；
- 指针可以存入字段、全局变量和容器；
- 指针不携带生命周期、边界或对象身份元数据；
- 指针与 `ptrsize` 之间可以通过 `ptrcast` 进行显式转换；
- 指针比较按照目标地址空间中的无符号数值地址定义。

下列指针操作都不要求特殊关键字：

- 复制、赋值和传递指针；
- 与 `null` 比较；
- 指针之间比较；
- 取得对象地址；
- 显式地址转换；
- 指针算术；
- `*pointer` 解引用；
- `pointer->member` 成员访问；
- `pointer[index]` 索引访问。

```ink
var pointer: File* = null;
pointer = &file;

if pointer != null {
    pointer->read();
}
```

访问原始指针时，程序员负责保证地址有效、范围足够、对齐正确、对象尚在生命周期内，并满足并发规则。违反这些前置条件可能产生 UB。

## 2. 短期引用

`T&` 与 `const T&` 是非空、非拥有的短期引用：

- `T&` 允许修改目标；
- `const T&` 只允许读取目标；
- 调用时编译器根据形参类型绑定引用，不要求调用方写取地址符；
- 引用访问使用普通的 `.`；
- 引用不能存入全局变量或长期对象字段；
- 引用不能被逃逸闭包或异步任务保存；
- 第一版不允许返回普通引用；
- Ink 不引入生命周期参数或完整借用检查器。

```ink
func inspect(file: const File&) {
    file.read();
}

inspect(file);
file.read(); // file 仍然有效
```

需要长期保存地址时必须使用原始指针：

```ink
class Task {
    file: File*;
}
```

这种规则只要求编译器进行简单的引用逃逸检查，不追踪任意原始指针的生命周期。

### 2.1 `Optional` 可以包含短期引用

Ink 不提供 `T?` 或 `T&?` 类型语法。需要表达“可能存在的短期引用”时，使用标准库泛型 `Optional<T&>` 或 `Optional<const T&>`：

```ink
let result: Optional<File&> = try_cast<File&>(resource);
```

- 非空内容仍遵守普通引用的非拥有和可变性规则；
- 使用成员前必须按照议题 33 通过 `if let .some(...)`、`match` 等模式语法解包；
- `Optional<T&>` 不能逃逸、存入长期字段或绕过普通引用的返回限制；
- 它不会把内部引用变成拥有型对象，也不会延长目标生命周期；
- 原始指针 `T*` 仍然自身可空。

`Optional<T>` 由标准库使用议题 32 的普通泛型枚举实现，并参与通用 niche 布局优化。普通参数绑定仍使用非空 `T&`。

### 2.2 异步成员函数的 `this` 不是短期引用

议题 54 规定异步成员函数保留普通成员调用语法，但任务帧中的隐式 `this` 使用非拥有原始指针表示。它不是允许 `T&` 逃逸的例外：

```ink
var task = object.operation_async();
// task 保存 &object；不保存可逃逸的 T&
```

该成员调用不会延长 `object` 生命周期，也不会建立一般的值到指针隐式转换。议题 54 额外要求接收对象保持在原地址并存活到异步成员任务最终结束；通过 `this` 访问成员时仍承担与任何 `T*` 相同的地址、对齐和并发前置条件。

## 3. 固定长度数组

`T[N]` 表示直接包含 `N` 个连续 `T` 元素的固定长度数组。`N` 是编译期常量，也是数组类型的一部分。

```ink
var values: int[4] = [10, 20, 30, 40];
```

数组的对象表示只包含元素本身，不额外保存运行时长度或数据指针：

```text
sizeof(T[N]) == sizeof(T) * N
```

具体大小还必须满足类型布局与尾部填充规则。`T[4]` 与 `T[8]` 是不同类型。

数组索引必须检查边界；由于长度编译期已知，编译器可以在证明安全时消除检查。数组作为类字段或局部变量时直接内联存储元素。

## 4. 安全切片

`T[]` 表示可写的非拥有切片，`const T[]` 表示只读非拥有切片。

切片是两个机器字的胖指针：

```text
Slice<T> = {
    data: T*,
    length: ptrsize,
}
```

在 64 位目标上，普通切片通常占 16 字节。长度保存在每个切片值中，不存放在数组前面，也不修改被引用对象的内存布局。

```ink
var numbers: int[5] = [10, 20, 30, 40, 50];

let all: const int[] = numbers[:];
let middle: const int[] = numbers[1..4];
```

概念表示为：

```text
all    = { &numbers[0], 5 }
middle = { &numbers[1], 3 }
```

安全切片遵守以下规则：

- 不拥有元素；
- 非空切片的完整元素范围必须有效；
- 空切片的 `length` 为零，此时 `data` 可以为 `null`；
- 索引始终执行边界检查，越界产生 trap；
- 子切片不复制元素，只产生新的指针和长度；
- 复制切片值只复制指针和长度，不复制元素；
- 与短期引用相同，安全切片不能逃逸到长期存储。

```ink
func sum(values: const int[]) -> int {
    var result = 0;

    for value in values {
        result += value;
    }

    return result;
}
```

## 5. 原始切片

需要长期保存“地址加长度”时，使用可复制的原始切片：

```ink
class RawSlice<T> {
    data: T*;
    length: ptrsize;
}
```

`RawSlice<T>` 可以存入字段、全局变量、闭包和异步任务。语言不验证它指向的存储是否仍然有效。通过原始切片访问元素时，程序员负责保证地址、长度、对齐和生命周期正确。

议题 43 同样允许可复制的原始指针和 `RawSlice<T>` 作为长期任务结果。安全引用和安全切片不能存入 `Task<T>` 的完成状态；不可复制资源的异步结果使用原始指针时，任务不取得指针目标的所有权，调用方仍负责完整生命周期。

议题 44 的惰性异步调用在创建任务时把原始指针或原始切片复制进任务帧。议题 54 的异步成员 `this` 也使用相同原始指针规则；以后才启动函数体不会自动延长其目标存储的生命周期。

```ink
func process(values: RawSlice<int>) {
    for index in 0 .. values.length {
        print(values.data[index]);
    }
}
```

`index < values.length` 只证明索引没有超过记录的长度，不能证明 `data` 实际指向这么多有效元素；构造错误的 `RawSlice<T>` 后进行访问可能产生 UB。

## 6. 数组、切片与指针的差异

| 特性 | 数组 `T[N]` | 安全切片 `T[]` | 原始指针 `T*` |
| --- | --- | --- | --- |
| 是否包含元素 | 是 | 否 | 否 |
| 是否拥有存储 | 作为值时拥有 | 否 | 否 |
| 长度 | 编译期类型的一部分 | 运行时保存在切片中 | 不保存 |
| 对象大小 | 约为 `N * sizeof(T)` | 两个机器字 | 一个机器字 |
| 子范围 | 通过生成切片表示 | 直接支持 | 可计算地址但无长度 |
| 索引检查 | 有，常可静态消除 | 有，运行时检查 | 无边界信息 |
| 能否长期保存 | 可以 | 不可以 | 可以 |
| 生命周期验证 | 对内联元素自然成立 | 通过不逃逸规则限制 | 由程序员负责 |

数组的优点是内联、紧凑、长度编译期已知并易于优化；缺点是不同长度属于不同类型，不能表示运行时长度。

切片的优点是可以用统一函数处理任意长度的数据、低成本表示子范围并进行边界检查；缺点是需要两个机器字、依赖底层对象生命周期，并且运行时索引通常需要检查。

原始指针的优点是表示最小、适合 FFI 和底层数据结构；缺点是没有长度信息，语言无法验证访问范围和生命周期。
